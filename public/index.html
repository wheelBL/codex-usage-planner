    如何理解这些数字

    100% 代表当前窗口的完整额度。计划预算使用“百分点”：例如消耗 10 个百分点，余量从 100% 变为 90%。计划为参考，不保证未来用量。

    休息日不分配预算仍可正常使用。重置卡需要在 Codex 中手动兑换；状态未知时不会视为没有卡片。数据过期或重置待核验时，请以服务端最终结果为准。

    托盘外环表示实际剩余，内环半圈表示符合计划。高于半圈为消耗偏快，低于半圈为消耗偏慢；悬停可查看精确差额。

    日期日历消耗预算事件

    本页是假设按计划消耗的容量分配，不是必须完成的每日用量或用卡指令。当前日只分配剩余时段。休息日计划预算为零；落在休息日的用卡提醒仅需手动兑换。计划不会自动兑换卡片。

    日历与计划

    同一建议仅提醒一次，可稍后提醒或当次静音。macOS 需允许系统通知。

    每日工作时段

    按工作日时区分配预算；不设置时段表示全天；结束时间 00:00 表示当天午夜。

    SSH 会话速度

    添加主机后，本机与全部启用的 SSH 主机会话一起参与最近活动统计。沿用系统 SSH 密钥与主机验证；请先在终端成功登录，不需要填写密码。远端需有 Python 3。

    Codex 的远程控制连接需要补充对应 SSH 地址；仅有远程控制 ID 时无法读取远端日志。

    高级设置：休假与重置卡

    0 表示休假，1 表示完整工作日，0.5 表示半天。自定义设置优先于法定节假日和调休。2027年等未核验年份会明确提示。
